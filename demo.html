heavens.js

A drop-in animated sky: blue heavens, sunlit clouds, heaven's gates and a floating glass codex — raymarched in one WebGL shader. No dependencies, no build step, no network. 18 KB.

Everything you can see behind this panel is the library. Try the controls:

Install

Copy heavens.js next to your HTML. That's the whole install.

<script src="heavens.js" data-heavens></script>

That one line creates a fixed, full-screen canvas behind your page (z-index:-1, pointer-events:none) so it never interferes with your existing layout or clicks.

Or control it yourself

<script src="heavens.js"></script>
<script>
  const sky = Heavens.mount({
    accent: 0xc2870b,   // colour of the light
    book:   false,      // hide the codex — just sky and clouds
    gates:  false,
    quality:'auto'
  });
</script>

Options

accentHex colour of the sunlight and glass tint. Default 0xc2870b.
bookShow the floating codex. Default true.
gatesShow heaven's gates. Default true.
cloudsShow cloud layers. Default true.
parallaxFollow the pointer. Auto-disabled on touch devices.
quality'auto' (adapts to measured frame time), 'low', or 'high'.
zIndexCanvas stacking. Default -1 — behind your content.

Methods

setAccent(hex)Retheme the light; it eases rather than jumping.
setLayers({…})Toggle book / gates / clouds at runtime.
setZoom(z, bloom)Dolly toward the codex and bloom to white (0–1 each).
bookRect()Codex rect in CSS pixels, for placing your own hit-area over it.
pause() / resume()Stop and start the render loop.
destroy()Remove it and release the GL context.

Performance

Raymarching is fill-rate bound, so the sky renders to a reduced-resolution buffer the browser scales up — invisible for a soft backdrop, and the difference between 60fps and a slideshow on a phone. Quality adapts to measured frame time, and the loop pauses automatically when the tab is hidden or the canvas scrolls out of view.

One caveat worth knowing: stacked backdrop-filter blurs over an animated canvas are expensive — each blurred panel makes the compositor re-sample the moving pixels beneath it. If your page has several frosted panels, drop the blur under roughly 900px wide (as this page does) and use a denser translucent background instead. Over a soft sky the difference is nearly invisible, and it is the single biggest mobile win available.

If WebGL is unavailable the canvas falls back to a CSS sky gradient, so the page never looks broken.
